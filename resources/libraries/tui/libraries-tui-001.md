# ratatui

![stars](https://img.shields.io/github/stars/ratatui/ratatui?style=flat) ![GitHub](https://img.shields.io/github/license/ratatui/ratatui)

> Ratatui 是一个用 rust 制作终端用户界面的板块。它是一个轻量级库，提供了一系列小工具和实用程序，用于构建复杂的 rust TUI。Ratatui 于 2023 年从 Tui-rs crate 分支出来，以便继续开发。
>
