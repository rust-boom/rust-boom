# GPUI Kit

![stars](https://img.shields.io/github/stars/longbridge/gpui-kit?style=flat) ![license](https://img.shields.io/badge/license-Apache--2.0-blue)

GPUI Kit 是基于 GPUI 构建 Rust 桌面应用的开发框架，整合了 UI 组件、行为与基础设施，并提供可选的 JavaScript 扩展运行时。

## 功能与适用场景

- `gpui-component` 提供带样式的组件系统，`gpui-base` 提供可用于构建自定义设计系统的行为与基础设施。
- 支持 WebAssembly、AccessKit 无障碍能力和 UI 集成测试。
- 适用于使用 GPUI 开发桌面应用或构建自定义 UI 系统。
