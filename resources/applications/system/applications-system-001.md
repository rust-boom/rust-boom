# RustScan

![stars](https://img.shields.io/github/stars/bee-san/RustScan?style=flat) ![GitHub](https://img.shields.io/github/license/bee-san/RustScan)

> RustScan 是端口扫描工具，可将发现的端口传递给 Nmap，并支持脚本扩展。扫描耗时取决于目标、网络和配置，不把上游特定测试中的秒数作为通用保证。
