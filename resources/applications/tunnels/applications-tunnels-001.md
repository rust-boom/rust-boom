# rathole

![stars](https://img.shields.io/github/stars/rathole-org/rathole?style=flat) ![GitHub](https://img.shields.io/github/license/rathole-org/rathole)

> 安全、稳定、高性能的内网穿透工具，用 Rust 语言编写
>
> rathole，类似于 [frp](https://github.com/fatedier/frp) 和 [ngrok](https://github.com/inconshreveable/ngrok)，可以让 NAT 后的设备上的服务通过具有公网 IP 的服务器暴露在公网上。
