# Koru

![stars](https://img.shields.io/github/stars/koruworks/mono?style=flat) ![GitHub](https://img.shields.io/github/license/koruworks/mono)

> Koru 是用 Rust 原生开发（非 Electron）的免费开源（MPL-2.0）本地优先工作区，用于管理笔记、文档和文件。笔记保存在设备上的本地数据库中，无需注册账号；支持从 Evernote、Notion、OneNote、Google Docs 和 Markdown 导入，并可导出为 Markdown/TextBundle。官方提供 Windows 和 macOS（Apple 芯片）版本。
