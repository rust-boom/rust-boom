# Bevy

![stars](https://img.shields.io/github/stars/bevyengine/bevy?style=flat) ![GitHub](https://img.shields.io/github/license/bevyengine/bevy)

> Bevy 是用 Rust 编写的开源数据驱动游戏引擎，采用 ECS（实体组件系统）架构，面向 2D 与 3D 游戏开发，支持按需组合功能模块。
