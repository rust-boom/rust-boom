# IDE TEA

![stars](https://img.shields.io/github/stars/fabiocmazzo/idetea?style=flat) ![GitHub](https://img.shields.io/github/license/fabiocmazzo/idetea)

> IDE TEA is a quiet, cross-platform IDE written in pure Rust with iced, for neurodivergent developers working alongside coding agents. Official builds are available for macOS, Linux, and Windows.
>
> IDE TEA 是用纯 Rust（iced）编写的安静、跨平台 IDE，面向神经多样性开发者，可与编程智能体协同工作。官方提供 macOS、Linux 和 Windows 安装包。
>
