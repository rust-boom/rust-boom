# cargo-edit

![stars](https://img.shields.io/github/stars/killercup/cargo-edit?style=flat) ![GitHub](https://img.shields.io/github/license/killercup/cargo-edit)

> cargo-edit 扩展 Cargo 的依赖版本管理，当前提供 cargo upgrade 和 cargo set-version。cargo add 与 cargo rm 已分别并入 Cargo 1.62 和 1.66，使用这些命令不必为新版 Cargo 安装旧版 cargo-edit。
